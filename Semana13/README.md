# Cálculo del total de una compra

**Nombre del estudiante:** Sandra Cecibel Cabrera Herrera

## Descripción

Este proyecto consiste en un programa desarrollado en Python que permite calcular el total de una compra. El programa utiliza una función que recibe como parámetros el precio de un producto y la cantidad de productos comprados. Luego realiza la multiplicación de estos valores y retorna el total de la compra.

## Funcionamiento

El usuario ingresa el precio del producto y la cantidad que desea comprar. El programa utiliza la función `calcular_total()` para realizar el cálculo y muestra el resultado en la consola.

* Python
